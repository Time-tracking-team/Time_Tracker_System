# Time Tracking System

A web-based Time Tracking System developed during a Software Engineering Internship at **Calibyte Private Limited**. The application enables teams to manage projects, track work hours, and generate productivity reports.

## Internship Details

| | |
|---|---|
| **Organization** | Calibyte Private Limited |
| **Role** | Software Engineering Intern / Team Member |
| **Project** | Time Tracking System |

## Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** PostgreSQL
- **API Testing:** Postman

## Features

- Admin and Team Member roles
- Project creation and management
- Time entry tracking
- Dashboard for monitoring work hours
- Reports for time and project analysis
- RESTful backend APIs built with Node.js and Express.js
- PostgreSQL database integration

## Getting Started

```bash
# Clone the repository
git clone https://github.com/Time-tracking-team/Time_Tracker_System.git

# Backend setup
cd backend
npm install
npm start

# Frontend setup (in a separate terminal)
cd frontend
npm install
npm start
```
